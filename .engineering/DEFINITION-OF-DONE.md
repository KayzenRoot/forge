# Definition of Done

An increment is done only when:
- admitted scope and acceptance criteria are satisfied;
- applicable tests/checks pass on the exact candidate;
- no known HIGH/CRITICAL defect remains;
- security/architecture/data/contracts are validated where applicable;
- Evidence Bundle binds base/head SHA, changed files, decisions, tests and risks;
- audit verdict is APPROVED;
- affected canonical documentation is truthful;
- checkpoint promotion occurs only after approval;
- merge/deployment/validation requirements for that increment are satisfied.

A PR, commit, implementation claim or historical green run is not sufficient evidence.
