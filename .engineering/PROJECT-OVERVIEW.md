# Project Overview

**Project:** Hive Forge  
**Stage:** Foundation / pre-implementation  
**Purpose:** governed software and product factory for the Hive ecosystem.

Forge will eventually provide reusable construction pipelines for web applications, APIs, dApps/Web3, games, AI applications and other startup products. It will integrate HIVE for context and GEF for governance from inception.

This document establishes direction only. Product capabilities are not considered implemented until admitted by Work Orders and proven by evidence.
