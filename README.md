# Hive Forge

Hive Forge is the software and product factory of the Hive ecosystem.

## Mission
Turn governed product intent into tested, evidenced, deployable software across web apps, dApps/Web3, APIs, games, desktop/mobile and AI products.

## Ecosystem
- **HIVE**: project context, memory, retrieval and governed task intake.
- **GEF Bootstrap v1.0.0**: engineering governance and evidence-first lifecycle.
- **Hive Core / Hades**: orchestration and shared intelligence.
- **Hive IRIS**: multimedia and asset production.
- **Forge**: software construction, validation, delivery and operations.
